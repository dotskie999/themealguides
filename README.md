# The Meal Guides - Frontend

## Getting Started

1. Extract this zip folder and open it in VS Code.
2. Open a terminal in VS Code and install dependencies:
   ```bash
   npm install
   ```
3. Update your `.env.local` file with your Google Apps Script Web App URL:
   ```env
   NEXT_PUBLIC_API_URL="your-web-app-url-here"
   ```
4. Run the development server:
   ```bash
   npm run dev
   ```
5. Open [http://localhost:3000](http://localhost:3000) in your browser.
